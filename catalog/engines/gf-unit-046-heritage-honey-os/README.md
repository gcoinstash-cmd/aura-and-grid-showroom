# 🏛️ Heritage & Honey — Premium Restaurant Template

Welcome to **Heritage & Honey**, an ultra-premium, luxury editorial web template custom-built for high-end restaurants, boutique chefs, and culinary brands. Engineered with a "Zen Minimalist" dark theme, fluid typography, smooth layout physics, and responsive structural integrity.

---

## ⚡ Quick Start

Get your development server up and running locally in less than a minute.

### 1. Install Dependencies
Navigate to the root directory and install the required modules:
```bash
npm install
# or
yarn install
```

### 2. Run Locally
Launch the fast local development server:
```bash
npm run dev
# or
yarn dev
```
Open `http://localhost:5173` in your browser to view the template.

### 3. Production Build
Compile and optimize the template for production deployment:
```bash
npm run build
```

---

## 🎨 Easy 1-File Customization

You do **not** need to dig through hundreds of lines of layout or animation logic to rebrand this website. Everything structural maps straight from a single configuration file.

Open **`src/data/templateData.ts`** to instantly edit:
* **Brand Assets:** Modify restaurant names, taglines, and brand copy.
* **Menu Architecture:** Instantly add or update dishes, prices, descriptions, and filtering categories (e.g., Vegan, Gluten-Free).
* **Narrative Copy:** Update the Executive Chef profile biography, images, and culinary journals.
* **Contact Details:** Change phone numbers, physical operational hours, and active social handles.

*Tip: For images, simply swap out the placeholder URLs with high-quality imagery from platforms like Unsplash.*

## 🚀 2-Click Production Deployment

This template is fully optimized for continuous delivery on modern hosting platforms.

### Option A: Deploy to Netlify (Recommended)
1. Push your template code to a GitHub, GitLab, or Bitbucket repository.
2. Log into your **Netlify Dashboard** and select **Add New Site** > **Import from Git**.
3. Select your repository. Netlify will automatically detect the build settings:
   * **Build Command:** `npm run build`
   * **Publish Directory:** `dist` (or `build` depending on your bundler framework)
4. Click **Deploy Site**. Your live luxury storefront is up!

### Option B: Deploy to Vercel
1. Install the Vercel CLI via `npm i -g vercel` or log into the Vercel web dashboard.
2. Import your repository directly.
3. Keep default framework settings and click **Deploy**.
