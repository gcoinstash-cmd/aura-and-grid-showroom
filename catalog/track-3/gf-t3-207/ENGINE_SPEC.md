PROPRIETARY MATHEMATICAL & ALGORITHMIC ENGINE ### 2.1 Concentrated Liquidity Mathematical Invariant Unlike standard full-range constant product automated market makers where capital is spread across (0, infinity), the APEX-207 AMM concentrates liquidity within an arbitrary user-defined price interval: Range: [p_a, p_b] where 0 < p_a < p_b The virtual reserve state (x_virt, y_virt) and actual physical reserves (x_real, y_real) satisfy: (x_real + L / sqrt(p_b)) * (y_real + L * sqrt(p_a)) = L^2 Where: - L is the liquidity scalar. - x_virt = x_real + L / sqrt(p_b) = L / sqrt(P) - y_virt = y_real + L * sqrt(p_a) = L * sqrt(P) - P is the active spot price in points (pts), defined as units of Reserve B per unit of Reserve A: P = y_virt / x_virt. #### Real Reserve Equations across Price Regimes: 1. **Regime 1 (P <= p_a - Below Lower Tick):** x_real = L * (1 / sqrt(p_a) - 1 / sqrt(p_b)), y_real = 0 Pool holds 100% Reserve A. 2. **Regime 2 (p_a < P < p_b - Active Concentration Range):** x_real = L * (1 / sqrt(P) - 1 / sqrt(p_b)) y_real = L * (sqrt(P) - sqrt(p_a)) Both Reserve A and Reserve B coexist dynamically. 3. **Regime 3 (P >= p_b - Above Upper Tick):** x_real = 0, y_real = L * (sqrt(p_b) - sqrt(p_a)) Pool holds 100% Reserve B. ### 2.2 Swap Exact Input Formula When a counterparty deposits delta_x_in of Reserve A: 1. Dynamic fee deduction: delta_x_fee = delta_x_in * Fee(t), where delta_x_net = delta_x_in - delta_x_fee. 2. Next virtual Reserve A: x_virt_new = x_virt + delta_x_net. 3. Next virtual Reserve B: y_virt_new = L^2 / x_virt_new. 4. Reserve B payout: delta_y_out = y_virt - y_virt_new. 5. New active price: P_new = y_virt_new / x_virt_new. ### 2.3 Closed-Form Analytical Impermanent Loss Formula Let P_0 be the entry price of the liquidity position and P_1 be the current mark price. Define the price ratio parameter k: k = P_1 / P_0 The exact closed-form analytical Impermanent Loss (IL) is given by: IL(k) = (2 * sqrt(k) / (1 + k)) - 1 #### Properties & Proofs: - **Identity at Parity:** For k = 1.0, IL(1.0) = (2 * sqrt(1) / (1 + 1)) - 1 = 2 / 2 - 1 = 0.0000%. - **Strict Concavity:** For all k > 0, k != 1, IL(k) < 0. - **Logarithmic Symmetry:** IL(k) == IL(1/k). Proof: IL(1/k) = (2 * sqrt(1/k) / (1 + 1/k)) - 1 = (2 / sqrt(k)) / ((k+1)/k) - 1 = (2 * sqrt(k) / (1 + k)) - 1 = IL(k) - **Analytical Benchmark Table:** - k = 1.10 (+10%): IL = -0.11% - k = 1.25 (+25%): IL = -0.62% - k = 1.50 (+50%): IL = -2.02% - k = 2.00 (+100%): IL = -5.72% - k = 3.00 (+200%): IL = -13.40% - k = 5.00 (+400%): IL = -25.46% ### 2.4 Dynamic Volatility-Scaled Fee Engine To insulate liquidity providers from toxic order flow and adverse selection during market stress, the fee rate adapts continuously to rolling return volatility: Fee(t) = Fee_base * (1 + alpha * (sigma_rolling / sigma_baseline)) Where: - Fee_base: Base pool fee (e.g. 30 basis points / 0.30%). - alpha: Volatility scaling sensitivity parameter (1.50). - sigma_baseline: Normal steady-state baseline volatility (0.0120). - sigma_rolling: Sample standard deviation of log price returns calculated over rolling window W = 50: r_i = ln(P_i / P_{i-1}), sigma_rolling = sqrt((1 / (W - 1)) * sum((r_i - mean_r)^2)) - Hard clamping boundaries: 5.0 <= Fee(t) <= 250.0 bps. ### 2.5 Capital Efficiency Multiplier The capital efficiency multiplier (CE) quantifies the depth concentration relative to a classic uniform (x * y = k) pool: CE = 1 / (1 - sqrt(p_a / p_b)) For symmetric interval [1.8000, 3.5000] around active price 2.5000: sqrt(1.8000 / 3.5000) = sqrt(0.514285) = 0.717137 CE = 1 / (1 - 0.717137) = 3.535x For narrow bands (e.g., [2.4500, 2.5500]), CE > 100x, enabling ultra-deep liquidity depth with a fraction of the committed balance. --- ## 3.
