Mathematical Derivation: R1CS to QAP Reduction ### 2.1 Rank-1 Constraint System (R1CS) An R1CS consists of three matrices A, B, C in Fr^(m x n) and a witness vector s in Fr^n where: - s_0 = 1 (constant generator) - (s_1, ..., s_l) are public inputs - (s_{l+1}, ..., s_{n-1}) are private witness values The satisfiability condition requires: (sum_{j=0}^{n-1} A_{i,j} s_j) * (sum_{j=0}^{n-1} B_{i,j} s_j) - (sum_{j=0}^{n-1} C_{i,j} s_j) = 0 for all i in {0, ..., m - 1}. ### 2.2 Quadratic Arithmetic Program (QAP) Transformation Let T = {t_0, t_1, ..., t_{m-1}} be arbitrary distinct roots of unity in Fr. Define Lagrange interpolation polynomials: - A_j(t_i) = A_{i,j} - B_j(t_i) = B_{i,j} - C_j(t_i) = C_{i,j} Define the target vanishing polynomial: t(x) = prod_{i=0}^{m-1} (x - t_i) The R1CS equation holds if and only if there exists a quotient polynomial h(x) in Fr[x] of degree at most m - 2 such that: (sum_{j=0}^{n-1} s_j A_j(x)) * (sum_{j=0}^{n-1} s_j B_j(x)) - sum_{j=0}^{n-1} s_j C_j(x) = h(x) * t(x) ### 2.3 Groth16 Trusted Setup & Verification Equation Given toxic waste simulation trapdoors (alpha, beta, gamma, delta, x) in Fr*: The verification key contains: - alpha * G1 in G1 - beta * G2 in G2 - gamma * G2 in G2 - delta * G2 in G2 - { (beta * A_i(x) + alpha * B_i(x) + C_i(x)) / gamma * G1 } for i = 0, ..., l - { (beta * A_i(x) + alpha * B_i(x) + C_i(x)) / delta * G1 } for i = l + 1, ..., n - 1 The Groth16 proof is the tuple pi = (A in G1, B in G2, C in G1).
