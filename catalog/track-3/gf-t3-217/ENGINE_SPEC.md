Proprietary Mathematical & Algorithmic Specifications ### 2.1 Prompt Token Shannon Entropy Derivation Let prompt sequence P contain N tokens drawn from vocabulary V. The empirical token frequency of token v_k is denoted f(v_k). The probability mass function is: ``` p(v_k) = f(v_k) / N ``` The normalized token entropy H_norm(P) is defined as: ``` H(P) = - Σ [ p(v_k) · log2(p(v_k)) ] for k = 1 to |V| H_max = log2(N) if N > 1 else 1.0 H_norm(P) = min(1.0, max(0.0, H(P) / H_max)) ``` Structural density S(P) combines token length, entropy, and cryptographic token dispersion: ``` S(P) = min(1.0, (N / 150.0) · 0.4 + H_norm(P) · 0.4 + seed_digest · 0.2) ``` Tier Selection Decision Boundaries: - `S(P) >= 0.72` ➔ Assign MODEL-TIER-ALPHA (Deep Reasoning) - `0.45 <= S(P) < 0.72` ➔ Assign MODEL-TIER-BRAVO (Balanced Speed) - `0.20 <= S(P) < 0.45` ➔ Assign MODEL-TIER-GAMMA (Low Latency Lite) - `S(P) < 0.20` ➔ Assign MODEL-TIER-DELTA (Deterministic Edge) ### 2.2 UCB1 Multi-Armed Bandit Dynamic Balancer Each model tier represents an arm i in set K = {Alpha, Bravo, Gamma, Delta}. Let N_i be the number of dispatches to arm i, and N = Σ N_k be total dispatches. Let X_bar_i be the empirical sample mean reward of arm i, where reward R_i is bounded in [0, 1] as a weighted combination of output quality Q_i and normalized latency inverse L_i: ``` R_i = 0.70 · Q_i + 0.30 · (1.0 - min(1.0, Latency_ms / 100.0)) ``` The Upper Confidence Bound (UCB1) score is: ``` UCB1_i = X_bar_i + c · sqrt( (2 · ln N) / N_i ) ``` where exploration parameter c = 1.414 (theoretical sqrt(2)). The router dispatches to argmax_i UCB1_i among healthy candidate tiers. ### 2.3 Circuit Breaker Finite State Machine For each tier i, the breaker tracks failure counter C_fail, recovery timer T_cool = 15.0 sec, and canary probe threshold P_thresh = 2: ``` State Transitions: 1. CLOSED ──(C_fail >= 3)──▶ OPEN 2. OPEN ──(Elapsed >= 15.0s)──▶ HALF_OPEN 3. HALF_OPEN ──(Canary Successes >= 2)──▶ CLOSED 4. HALF_OPEN ──(Canary Failure == 1)──▶ OPEN (Reset Timer) ``` --- ## 3.
