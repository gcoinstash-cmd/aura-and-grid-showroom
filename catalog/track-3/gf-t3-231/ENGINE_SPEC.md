Mathematical Formulation (Zero-Copy Cast & Dynamic Scaling) ### 3.1 Dual Format Bit Layouts - **E4M3 Layout (`[S | EEEE | MMM]`)**: - Sign bit `S`: 1 bit - Exponent `E`: 4 bits, bias `B = 7` - Mantissa `M`: 3 bits (`8` discrete steps per binade) - Maximum Normal Value: `V_max(E4M3) = (1 + 6/8) * 2^(15 - 7) = 1.75 * 256 = 448.0` - Minimum Positive Normal: `2^(-6) = 0.015625` - Minimum Positive Subnormal: `2^(-9) = 0.001953125` - **E5M2 Layout (`[S | EEEEE | MM]`)**: - Sign bit `S`: 1 bit - Exponent `E`: 5 bits, bias `B = 15` - Mantissa `M`: 2 bits (`4` discrete steps per binade) - Maximum Normal Value: `V_max(E5M2) = (1 + 3/4) * 2^(30 - 15) = 1.75 * 32768 = 57344.0` - Minimum Positive Normal: `2^(-14) = 0.00006103515625` - Minimum Positive Subnormal: `2^(-16) = 0.0000152587890625` ### 3.2 Block-Wise Amax & Dynamic Scale Factor Given a contiguous tensor block `X = [x_1, x_2, ..., x_N]`: 1. **Absolute Maximum Reduction**: `amax(X) = max_{i in 1..N} |x_i|` 2. **Staged Hardware Scale Factor**: `scale_staged = 1.75 / max(amax(X), 1e-6)` `encode_multiplier = V_max(format) * 2^(-margin_bits) / max(amax(X), 1e-12)` 3. **Quantize & Dequantize Reconstruction**: `x_q = clip_and_round_fp8(x_i * encode_multiplier, format)` `x_hat = x_q / encode_multiplier` 4. **Signal-to-Noise Ratio (SNR dB)**: `SNR_dB = 10 * log10( sum(x_i^2) / sum((x_i - x_hat_i)^2) )` --- ## 4.
