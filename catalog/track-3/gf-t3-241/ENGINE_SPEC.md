Mathematical Foundations ### 2.1 Speculative Target-Draft Acceptance Criterion For each candidate draft token `x_i` sampled from draft model distribution `P_draft(x | prefix)` and evaluated in parallel against target model distribution `P_target(x | prefix)`: ```text alpha_i = min(1.0, P_target(x_i) / P_draft(x_i)) ``` A uniform verification threshold `u_i in [0, 1]` accepts `x_i` iff `u_i <= alpha_i` and all ancestor tokens `x_0 ... x_{i-1}` along the tree branch were accepted. ### 2.2 Exact Residual Recovery Distribution When a draft candidate at depth `k` is rejected, the engine samples a replacement token from the adjusted residual distribution: ```text P_residual(x) = max(0.0, P_target(x) - P_draft(x)) / sum_v max(0.0, P_target(v) - P_draft(v)) ``` This guarantees that the marginal distribution of emitted tokens matches `P_target(x)` with zero mathematical divergence (`L_inf < 1e-9`). ### 2.3 Non-Flat Tree Attention Causal Masking Given `N` candidate draft nodes across `B = 8` parallel branches with parent index vector `pi`, the causal mask matrix `M in {0, 1}^{N x N}` is defined as: ```text M[i, j] = 1 if j in Ancestors(i) union {i} M[i, j] = 0 otherwise ``` This allows a single target forward pass to evaluate all `B = 8` draft branches concurrently without cross-branch attention leakage. ### 2.4 Dynamic KV Cache Pointer Rollback Given base KV pointer `P_base`, draft depth `L_draft`, accepted depth `L_acc`, and page stride `S = 0x100`: ```text P_allocated = P_base + L_draft * S P_restored = P_base + L_acc * S Slots_reclaimed = L_draft - L_acc ``` ## 3.
