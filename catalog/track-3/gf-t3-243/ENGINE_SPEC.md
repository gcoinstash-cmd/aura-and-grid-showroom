It compresses continuous 16-bit floating-point activation and weight blocks into a hybrid packed ternary (`{-1, 0, +1}`) plus 6-bit `E3M2` (1 sign bit, 3 exponent bits, 2 mantissa bits) outlier stream, sustaining `8,000 GB/s` quantization bandwidth saturation at `0.01 µs` dynamic scale latency across `16` active register blocks (`B0..B15`). --- ## 2. Core Mathematical Formulations ### 3.1 Dynamic Block Scale Calculation (Gamma) Given a continuous weight block vector `W` of length `N`, the baseline absolute mean scale `gamma_raw` is computed as: ```text gamma_raw = (1 / N) * sum_{i=0}^{N-1} |W_i| ``` Outlier channels are isolated where `|W_i| >= tau * gamma_raw` (default `tau = 2.45`). The refined inlier scaling factor `gamma` is then computed across the inlier index set `I`: ```text gamma = (1 / |I|) * sum_{i in I} |W_i| ``` ### 3.2 Multi-Plane Ternary Weight Projection For every inlier index `i in I`, continuous weights are projected into discrete ternary trits `T_i in {-1, 0, +1}` via round-to-nearest clamping: ```text T_1(W_i) = clip(round(W_i / (gamma + epsilon)), -1, +1) ``` To maintain Signal-to-Quantization-Noise Ratio (`SQNR >= 48.0 dB`), residual stages `k in {2, 3, 4}` with geometric decay scales `gamma_k = gamma * 3^{-(k-1)}` are bit-packed into the 6-bit `FP6` container frame. ### 3.3 6-Bit E3M2 Outlier Channel Encoding High-magnitude outlier activations `i not in I` are routed to the 6-bit `E3M2` floating-point format: - **Bit 5**: Sign bit `S in {0, 1}` - **Bits 4..2**: 3-bit biased exponent `E in [0..7]` with bias `B = 3` - **Bits 1..0**: 2-bit fractional mantissa `M in [0..3]` Reconstructed value for normal numbers (`E >= 1`): ```text V_recon = (-1)^S * (1 + M / 4) * 2^(E - 3) ``` Reconstructed value for subnormal numbers (`E == 0`): ```text V_recon = (-1)^S * (M / 4) * 2^(-2) ``` ### 3.4 Signal-to-Quantization-Noise Ratio (SQNR) ```text SQNR_dB = 10 * log10( sum(W_i^2) / sum((W_i - W_hat_i)^2) ) ``` --- ## 4.
