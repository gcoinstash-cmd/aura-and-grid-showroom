# GF-T3-249 ## 1. Architectural Overview GF-T3-249 is a clean-room Track 3 distributed Mixture-of-Experts (MoE) Expert Parallelism and Top-2 Routing engine. It evaluates token gating probabilities across 8 dedicated expert GPU ranks (`E0` through `E7`), enforces capacity factor thresholds with zero dropped tokens, and computes auxiliary load-balancing loss in sub-microsecond shared memory passes. ## 2. Core Mathematical Formulation ### 3.1 Softmax Gating Network Given an incoming token representation vector `x` in `R^d` and an expert gating weight matrix `W_g` in `R^(d x E)` across `E = 8` experts: ```text h(x) = x · W_g p_i(x) = exp(h(x)_i - max_k h(x)_k) / sum_{j=1..E} exp(h(x)_j - max_k h(x)_k) ``` ### 3.2 Top-2 Expert Selection & Normalized Gating Weights The router selects the top two indices `(k_1, k_2) = argmax_2(p(x))` and normalizes their active combination weights: ```text g_1 = p_{k_1}(x) / (p_{k_1}(x) + p_{k_2}(x)) g_2 = p_{k_2}(x) / (p_{k_1}(x) + p_{k_2}(x)) y(x) = g_1 · E_{k_1}(x) + g_2 · E_{k_2}(x) ``` ### 3.3 Capacity Factor & Zero-Drop Token Redistribution For batch size `T = 2,944` tokens, expert count `E = 8`, and capacity factor `CF = 1.25`: ```text MaxCapacity(E_i) = ceil((T / E) * CF) = ceil((2944 / 8) * 1.25) = 460 Tokens ``` When an expert rank reaches `MaxCapacity(E_i)`, excess tokens are dynamically rerouted via All-to-All NVLink mesh to secondary Top-2 expert ranks with available headroom, guaranteeing `DroppedTokens = 0`. ### 3.4 Auxiliary Load-Balancing Loss & Router Z-Loss To prevent expert collapse and maintain uniform utilization across all 8 GPU ranks: ```text L_aux = alpha * E * sum_{i=1..E} (f_i * P_i) L_z = (1 / E) * (log(sum_{j=1..E} exp(h(x)_j)))^2 ``` where `f_i` is the fraction of tokens dispatched to expert `i`, `P_i` is the mean routing probability allocated to expert `i`, and `alpha = 0.0012`. ## 4.
