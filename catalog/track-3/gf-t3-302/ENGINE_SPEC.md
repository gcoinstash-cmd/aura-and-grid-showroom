## 3. Mathematical Formulation

### 3.1 Parallel Target Forward Evaluation

Given a drafted candidate sequence `tau_draft = [t_0, t_1, ..., t_7]` generated by a lightweight draft estimator `M_draft`, the target model `M_target` evaluates all 8 candidate positions in a single coalesced forward pass:

```text
S_spec = M_target(tau_draft)
```

### 3.2 Exact Target Distribution Preservation

For each candidate position `i in {0..7}`, let `q(t_i)` denote the draft probability and `p(t_i)` denote the target probability computed during the parallel verification pass. Candidate `t_i` is accepted with probability:

```text
alpha_i = min(1.0, p(t_i) / q(t_i))
```

When a candidate `t_k` is rejected, the Non-Blocking Candidate Recycler immediately reclaims arenas `D_k .. D_7` across streaming multiprocessors without host synchronization stalls and samples a corrected token from the residual distribution:

```text
p_residual(t) = normalize(max(0.0, p(t) - q(t)))
```

### 3.3 Expected Token Yield Per Verification Cycle

With mean candidate acceptance rate `alpha` across `gamma = 8` speculative lanes, the expected verified tokens emitted per single target pass is:

```text
E[Tokens] = (1 - alpha^(gamma + 1)) / (1 - alpha)
```
