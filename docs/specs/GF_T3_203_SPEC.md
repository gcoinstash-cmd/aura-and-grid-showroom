Mathematical Architecture (Gate 1) ### 2.1 State-Space Dynamic Hedge Ratio ($\beta$) Estimation Pairs trading relies on the assumption that a linear combination of two non-stationary asset price series $y_t$ (Asset Y) and $x_t$ (Asset X) forms a stationary, mean-reverting spread: $$y_t = \beta_t x_t + \alpha_t + \epsilon_t$$ In real financial markets, the hedge ratio $\beta_t$ and intercept $\alpha_t$ drift over time due to structural macro shifts, liquidity shocks, and capital reallocation. Static Ordinary Least Squares (OLS) over rolling windows introduces window lag and boundary sensitivity. APEX-203 resolves this by formulating cointegration as an optimal stochastic state-space system. #### State Vector & Observation Formulation The unobserved hidden state $\theta_t \in \mathbb{R}^2$ represents the dynamic regression parameters: $$\theta_t = \begin{bmatrix} \beta_t \\ \alpha_t \end{bmatrix}$$ 1. **State Transition Equation (Random Walk / Parameter Drift)**: $$\theta_t = F \theta_{t-1} + w_t, \quad w_t \sim \mathcal{N}(0, Q)$$ Where: - $F = I_2 = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$ (Identity state transition) - $Q = \begin{bmatrix} q_\beta & 0 \\ 0 & q_\alpha \end{bmatrix}$ (Process noise covariance matrix, modeling parameter flexibility) 2. **Measurement / Observation Equation**: $$y_t = H_t \theta_t + v_t, \quad v_t \sim \mathcal{N}(0, R)$$ Where: - $y_t$ is the observed market price of Asset Y at tick $t$. - $H_t = \begin{bmatrix} x_t & 1 \end{bmatrix} \in \mathbb{R}^{1 \times 2}$ is the observation matrix formed by Asset X price. - $R \in \mathbb{R}$ is the scalar measurement noise variance. #### Kalman Recursive Update Equations Each incoming market tick $(y_t, x_t)$ executes a two-phase recursive update: 1. **Time Update (Prediction)**: $$\hat{\theta}_{t|t-1} = \hat{\theta}_{t-1|t-1}$$ $$P_{t|t-1} = P_{t-1|t-1} + Q$$ Where $P_{t|t-1} \in \mathbb{R}^{2 \times 2}$ is the prior error covariance matrix. 2. **Measurement Residual (Innovation)**: $$\hat{y}_{t|t-1} = H_t \hat{\theta}_{t|t-1} = \hat{\beta}_{t|t-1} x_t + \hat{\alpha}_{t|t-1}$$ $$e_t = y_t - \hat{y}_{t|t-1}$$ 3. **Innovation Covariance & Kalman Gain**: $$F_t = H_t P_{t|t-1} H_t^T + R = x_t^2 P_{00} + 2 x_t P_{01} + P_{11} + R$$ $$K_t = \frac{P_{t|t-1} H_t^T}{F_t} = \begin{bmatrix} \frac{x_t P_{00} + P_{01}}{F_t} \\ \frac{x_t P_{10} + P_{11}}{F_t} \end{bmatrix}$$ 4. **Measurement Update (Correction)**: $$\hat{\theta}_{t|t} = \hat{\theta}_{t|t-1} + K_t e_t$$ $$P_{t|t} = (I_2 - K_t H_t) P_{t|t-1}$$ To eliminate numerical drift and preserve positive semi-definiteness: $$P_{t|t} \leftarrow \frac{P_{t|t} + P_{t|t}^T}{2}, \quad P_{ii} \leftarrow \max(P_{ii}, 10^{-12})$$ 5. **Dynamic Spread Extraction**: $$\text{Spread}_t = y_t - (\hat{\beta}_{t|t} x_t + \hat{\alpha}_{t|t})$$ --- ### 2.2 Rolling Z-Score via Welford’s Algorithm (O(1) Numerical Stability) Computing sample mean and variance via naive sum-of-squares ($\sum x^2 - \frac{(\sum x)^2}{N}$) suffers from **catastrophic cancellation** in 64-bit floating point arithmetic when tick magnitudes are large (e.g. BTC prices $\sim 65,000$). APEX-203 implements an $O(1)$ time and $O(1)$ space sliding-window adaptation of **Welford’s algorithm**: #### Welford Formulations For a sample stream $\{s_1, s_2, \dots, s_k\}$: $$M_k = M_{k-1} + \frac{s_k - M_{k-1}}{k}$$ $$S_k = S_{k-1} + (s_k - M_{k-1})(s_k - M_k)$$ $$\sigma_k^2 = \frac{S_k}{k - 1}$$ For a fixed sliding window of size $N$ with incoming tick $s_{\text{new}}$ and evicted tick $s_{\text{old}}$: $$\Delta_{\text{in}} = s_{\text{new}} - M_{\text{old}}$$ $$M_{\text{new}} = M_{\text{old}} + \frac{s_{\text{new}} - s_{\text{old}}}{N}$$ $$\Delta_{\text{out}} = s_{\text{old}} - M_{\text{new}}$$ $$S_{\text{new}} = S_{\text{old}} + (s_{\text{new}} - s_{\text{old}})(s_{\text{new}} - M_{\text{new}} + s_{\text{old}} - M_{\text{old}})$$ #### Zero-Division & Degeneracy Protection $$Z_t = \begin{cases} \frac{\text{Spread}_t - M_t}{\sqrt{\sigma_t^2 + \epsilon}} & \text{if } \sigma_t > 10^{-8} \\ 0.0 & \text{otherwise} \end{cases}$$ Where $\epsilon = 10^{-8}$ prevents division-by-zero during low-volatility regimes. --- ### 2.3 Ornstein-Uhlenbeck (OU) Mean-Reversion Half-Life Estimation To confirm whether the cointegrated spread exhibits statistically actionable mean-reverting properties, the spread is modeled as a continuous Ornstein-Uhlenbeck stochastic process: $$d S_t = \theta (\mu - S_t) dt + \sigma dW_t$$ Where: - $\theta > 0$ is the mean-reversion speed. - $\mu$ is the long-term equilibrium spread. - $\sigma$ is the diffusion volatility. - $W_t$ is standard Brownian motion. #### Discrete AR(1) Parameter Estimation Discretizing with tick step $\Delta t = 1$: $$S_t = a + b S_{t-1} + \eta_t$$ Where: $$b = e^{-\theta \Delta t} \implies \theta = -\ln(b)$$ $$\mu = \frac{a}{1 - b}$$ Using Ordinary Least Squares (OLS) over window $W$: $$b = \frac{\sum_{i=1}^{W} (S_{i-1} - \bar{S}_{-1})(S_i - \bar{S}_0)}{\sum_{i=1}^{W} (S_{i-1} - \bar{S}_{-1})^2}$$ #### Analytical Half-Life $\tau_{1/2}$ The time required for the spread deviation to decay by $50\%$ towards equilibrium: $$\tau_{1/2} = \frac{\ln(2)}{\theta} = -\frac{\ln(2)}{\ln(b)}$$ **Boundary Diagnostics**: - If $b \ge 1$ or $b \le 0$: The process is non-stationary, random-walk, or explosive. Flagged as `isMeanReverting = false` ($\tau_{1/2} = \infty$). - If $0 < b < 1$: Finite half-life confirming cointegrated mean reversion. --- ### 2.4 Trade Signal Emitter Finite State Machine (FSM) ``` +---------------------------------------------+ | FLAT | +---------------------------------------------+ | | Z <= -2.0 Z >= +2.0 v v +-----------------------+ +-----------------------+ | LONG_SPREAD | | SHORT_SPREAD | | (Buy Y, Short Beta*X) | | (Short Y, Buy Beta*X) | +-----------------------+ +-----------------------+ | | | | Z >= -0.5 |Z| >= 3.5 Z <= +0.5 |Z| >= 3.5 | | | | v v v v [EXIT_NEUTRAL] [STOP_OUT] [EXIT_NEUTRAL] [STOP_OUT] ``` 1. **ENTER_LONG_SPREAD** ($Z_t \le -2.0$): Asset Y is severely undervalued relative to Asset X. Long 1.0 unit of Asset Y, Short $\beta_t$ units of Asset X. 2. **ENTER_SHORT_SPREAD** ($Z_t \ge +2.0$): Asset Y is severely overvalued relative to Asset X. Short 1.0 unit of Asset Y, Long $\beta_t$ units of Asset X. 3. **EXIT_NEUTRAL** (Spread reversion: $Z_t \ge -0.5$ for Long Spread, $Z_t \le +0.5$ for Short Spread). 4. **STOP_OUT** ($|Z_t| \ge 3.5$): Structural divergence or regime breakdown.
