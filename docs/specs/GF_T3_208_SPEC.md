Proprietary Mathematical & Algorithmic Engine #### 2.1 Black-76 Pricing & Analytical Greeks For forward underlying price F (pts), strike K (pts), time to maturity T (years), risk-free discounting factor D = exp(-r * T), and volatility sigma: d1 = (ln(F / K) + 0.5 * sigma^2 * T) / (sigma * sqrt(T)) d2 = d1 - sigma * sqrt(T) European Call Price: C(F, K, T, sigma) = D * (F * N(d1) - K * N(d2)) European Put Price: P(F, K, T, sigma) = D * (K * N(-d2) - F * N(-d1)) Analytical Greeks: - Delta (Call): dC / dF = D * N(d1) - Delta (Put): dP / dF = D * (N(d1) - 1.0) - Gamma: d2C / dF2 = D * n(d1) / (F * sigma * sqrt(T)) - Vega: dC / d(sigma) = D * F * sqrt(T) * n(d1) - Theta: -(D * F * n(d1) * sigma) / (2 * sqrt(T)) - r * D * (F * N(d1) - K * N(d2)) Where N(x) is the cumulative standard normal distribution and n(x) = (1 / sqrt(2 * pi)) * exp(-0.5 * x^2). #### 2.2 Brenner-Subrahmanyam (1988) Inversion Seed To avoid Newton-Raphson divergence in extreme wings or shallow vega regimes, the initial volatility seed sigma_0 is analytically derived from Brenner-Subrahmanyam: sigma_0 = sqrt(2 * pi / T) * |Price - 0.5 * (F - K)| / F The Newton-Raphson update step: sigma_(n+1) = sigma_n - (Black76(sigma_n) - MarketPrice) / Vega(sigma_n) Guarded by bisection bounds [0.0001, 5.0000] with convergence tolerance epsilon = 1e-7 pts. #### 2.3 Hagan et al. (2002) Closed-Form SABR Formula Under the SABR dynamic model: dF_t = alpha_t * (F_t)^beta * dW_t^(1) dalpha_t = nu * alpha_t * dW_t^(2) E[dW_t^(1) * dW_t^(2)] = rho * dt With fixed beta = 0.70, the Hagan et al. closed-form asymptotic expansion for implied volatility sigma_SABR(F, K, T) is computed as follows: Let one_minus_beta = 1.0 - beta Let fk = F * K Let sqrt_fk = sqrt(fk) Let fk_beta = sqrt_fk^one_minus_beta Let log_fk = ln(F / K) Case A: At-The-Money (F == K): sigma_ATM = (alpha / (F^one_minus_beta)) * [ 1.0 + ( ((one_minus_beta^2) / 24.0) * (alpha^2 / (F^(2 * one_minus_beta))) + 0.25 * (rho * beta * nu * alpha / (F^one_minus_beta)) + ((2.0 - 3.0 * rho^2) / 24.0) * nu^2 ) * T ] Case B: General (F != K): z = (nu / alpha) * fk_beta * log_fk chi(z) = ln((sqrt(1.0 - 2.0 * rho * z + z^2) + z - rho) / (1.0 - rho)) Denominator: Denom = fk_beta * [ 1.0 + ((one_minus_beta^2) / 24.0) * (log_fk^2) + ((one_minus_beta^4) / 1920.0) * (log_fk^4) ] Multiplier: Mult = 1.0 + [ ((one_minus_beta^2) / 24.0) * (alpha^2 / (fk^one_minus_beta)) + 0.25 * (rho * beta * nu * alpha / fk_beta) + ((2.0 - 3.0 * rho^2) / 24.0) * nu^2 ] * T sigma_SABR = (alpha / Denom) * (z / chi(z)) * Mult #### 2.4 Arbitrage-Free Verification Proofs 1. Calendar Arbitrage Monotonicity: Total implied variance w(K, T) = (sigma_SABR(K, T))^2 * T. For any two maturities T1 < T2 at strike K: w(K, T2) - w(K, T1) >= 0 A negative spread indicates calendar spread arbitrage and allows riskless cashflow extraction. 2. Butterfly Arbitrage & Breeden-Litzenberger Risk-Neutral Density: q(K) = exp(r * T) * (d2C / dK2) >= 0 for all strikes K. Evaluated via second-order central difference stencil: d2C / dK2 = 2.0 * ((C_(i+1) - C_i) / (K_(i+1) - K_i) - (C_i - C_(i-1)) / (K_i - K_(i-1))) / (K_(i+1) - K_(i-1)) If q(K) < 0, a long butterfly spread (Buy K-h, Sell 2*K, Buy K+h) yields a negative cost (strictly positive free points), violating no-arbitrage bounds. --- ### 3.
