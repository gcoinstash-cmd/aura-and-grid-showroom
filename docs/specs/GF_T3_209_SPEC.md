Proprietary Mathematical & Algorithmic Derivations ### 2.1 Peaks-Over-Threshold Extreme Value Theory (EVT) Let empirical loss be defined as L = -R, where R is the portfolio return vector. For a sufficiently high loss threshold u (calibrated at the 95th empirical percentile), the conditional excess distribution F_u(y) = P(L - u <= y | L > u) converges asymptotically to the Generalized Pareto Distribution (GPD): ``` G_{xi, beta}(y) = 1 - (1 + (xi * y) / beta)^(-1 / xi) ``` Where: - xi is the shape parameter (tail index, Fréchet domain for xi > 0). - beta is the scale parameter (beta > 0). The unconditional loss distribution tail (for L > u) is given by: ``` P(L > x) = P(L > u) * P(L - u > x - u | L > u) = (N_u / N) * (1 + (xi * (x - u)) / beta)^(-1 / xi) ``` Inverting at tail probability (1 - alpha): ``` VaR_alpha = u + (beta / xi) * [ ((N / N_u) * (1 - alpha))^(-xi) - 1 ] ``` Integrating the tail conditional expectation yields the closed-form Expected Shortfall (CVaR): ``` ES_alpha = E[ L | L > VaR_alpha ] = (VaR_alpha / (1 - xi)) + ((beta - xi * u) / (1 - xi)) ``` This mathematical identity guarantees coherence: because xi < 1 and beta > 0, ES_alpha is strictly greater than or equal to VaR_alpha across all confidence intervals. --- ### 2.2 Parametric Cornish-Fisher Expansion To adjust the standard Gaussian quantile z_alpha for non-normality without empirical loss of degrees of freedom, the Cornish-Fisher asymptotic inversion of the Edgeworth expansion is computed: ``` z_{CF} = z_alpha + (S / 6) * (z_alpha^2 - 1) + (K / 24) * (z_alpha^3 - 3 * z_alpha) - (S^2 / 36) * (2 * z_alpha^3 - 5 * z_alpha) ``` Where: - S is the sample skewness. - K is the sample excess kurtosis (K = mu_4 / sigma^4 - 3). - z_alpha is the exact inverse normal quantile. When S = 0 and K = 0: ``` z_{CF} = z_alpha + 0 + 0 - 0 = z_alpha ``` Proving exact convergence to standard Gaussian parametric VaR. --- ### 2.3 Hull-White Volatility-Updating Historical Simulation Historical returns r_t are non-stationary due to volatility clustering. The Hull-White mechanism dynamically updates each historical return observation r_t to current volatility regime sigma_T: ``` r_t^* = r_t * (sigma_T / sigma_t) ``` Where volatility evolves under an Exponentially Weighted Moving Average (EWMA) process with decay factor lambda = 0.94: ``` sigma_t^2 = (1 - lambda) * r_{t-1}^2 + lambda * sigma_{t-1}^2 ``` --- ### 2.4 Multi-Asset Correlated Monte Carlo Engine For asset weight vector w and dynamic 3x3 covariance matrix Sigma, Cholesky factorization calculates the unique lower triangular matrix L such that: ``` L * L^T = Sigma ``` For uncorrelated standard normal variates Z ~ N(0, I_3), correlated shock vectors are generated: ``` X = L * Z ``` Simulating 10,000 daily paths yields the full empirical portfolio loss distribution: ``` Loss_p = - w^T * X * Exposure_Units ``` --- ### 2.5 Regulatory Backtesting Validation Suite #### Kupiec Proportion of Failures (POF) Likelihood Ratio Tests the null hypothesis that empirical breach probability p_hat equals the nominal risk level p = 1 - alpha: ``` LR_{POF} = -2 * ln [ ( (1 - p)^(N - x) * p^x ) / ( (1 - p_hat)^(N - x) * p_hat^x ) ] ~ Chi^2(1) ``` Where N is total trading days (e.g., 250) and x is the count of realized losses exceeding VaR. #### Christoffersen Independence Test Evaluates whether risk breaches cluster over time using a first-order two-state Markov chain (0 = no breach, 1 = breach): ``` LR_{ind} = -2 * ln [ ( pi_0^(n_01 + n_11) * (1 - pi_0)^(n_00 + n_10) ) / ( pi_01^n_01 * (1 - pi_01)^n_00 * pi_11^n_11 * (1 - pi_11)^n_10 ) ] ~ Chi^2(1) ``` Combined conditional coverage: ``` LR_{cc} = LR_{POF} + LR_{ind} ~ Chi^2(2) ``` --- ## 3.
