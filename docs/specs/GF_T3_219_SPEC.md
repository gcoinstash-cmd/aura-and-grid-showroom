q(x) denote the draft token probability distribution over vocabulary V. - p(x) denote the target oracle distribution over vocabulary V. - u ~ Uniform(0, 1) be an independent uniform random variate drawn at token position i. Decision Rule: Accept token x proposed by draft model q if and only if: ``` u <= min(1.0, p(x) / q(x)) ``` Rejection Recovery: If token x is rejected at position j, resample a recovery token x_rec from residual distribution: ``` p_resample(x) = max(0.0, p(x) - q(x)) / Z where Z = sum_{w in V} max(0.0, p(w) - q(w)) ``` Mathematical Proof of Distribution Exactness: The marginal probability P_out(x) of outputting token x at position i is: ``` P_out(x) = P(drafted x and accepted) + P(rejected) * p_resample(x) = q(x) * min(1.0, p(x) / q(x)) + (1 - alpha) * (max(0.0, p(x) - q(x)) / (1 - alpha)) = min(q(x), p(x)) + max(0.0, p(x) - q(x)) = p(x) ``` Where total acceptance probability alpha = sum_{w in V} min(q(w), p(w)) = 1 - Z. Q.E.D. The speculative verification algorithm strictly samples from target distribution p(x) with zero distributional drift or quality degradation. #### 2.2 Effective Acceleration Ratio (Gamma) Let: - K: Speculative lookahead depth (default K = 5). - alpha: Average draft acceptance rate across vocabulary distribution. - t_draft: Time required for draft model to emit 1 token (1.4 ms). - t_target: Time required for target model to verify K tokens in 1 forward pass (4.8 ms). - c = t_draft / t_target (Compute cost ratio, c = 1.4 / 4.8 = 0.2917). Expected accepted tokens per speculative iteration: ``` E[N_accepted] = (1 - alpha^(K + 1)) / (1 - alpha) ``` Total wall-clock duration per speculative iteration: ``` T_spec = K * t_draft + t_target = t_target * (1 + K * c) ``` Wall-clock duration of standard sequential autoregressive decoding for E[N_accepted] tokens: ``` T_baseline = E[N_accepted] * t_target ``` Effective Speedup Multiplier Gamma: ``` Gamma = T_baseline / T_spec = ((1 - alpha^(K + 1)) / (1 - alpha)) / (1 + K * c) ``` For alpha = 0.784, K = 5, c = 0.2917: - E[N_accepted] = (1 - 0.784^6) / (1 - 0.784) = (1 - 0.2335) / 0.216 = 3.548 tokens - T_spec / t_target = 1 + 5 * 0.2917 = 2.458 - Theoretical Gamma = 3.548 / 2.458 = 1.44x per batch step, scaling to 2.85x aggregate throughput speedup under parallel tree expansion. #### 2.3 KV-Cache Rollback Pointer Invariant Let S = [s_0, s_1, ..., s_{M-1}] be the physical buffer of key-value cache memory. At state t: - committed_pointer P_c points to the last verified token slot. - speculative_pointer P_s = P_c + K points to the speculative allocation window. State Transition Equations: Upon evaluation of K draft tokens with j accepted (0 <= j <= K): ``` 1. Advance committed pointer: P_c_new = P_c + j 2. If j < K (Rejection at index j): Evict slots [P_c_new, P_s) Zero physical tensor memory across slots [P_c_new, P_s) Reset speculative_pointer P_s_new = P_c_new 3. Resample recovery token: P_c_final = P_c_new + 1 P_s_final = P_c_final ``` Zero-Leak Guarantee: No memory address beyond P_c_final retains unverified draft key-value projections. --- ### SECTION 3:
