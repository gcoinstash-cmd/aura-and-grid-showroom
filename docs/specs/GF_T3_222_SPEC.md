Proprietary Mathematical & Algorithmic Engine ### 2.1 Compressed Radix Tree Complexity & Longest Prefix Proofs Let `Sigma` denote the discrete token vocabulary and let a token sequence of length `L` be defined as `S = (t_1, t_2, ..., t_L)` in `Sigma^L`. Each node `u` in `V` within the compressed Radix Tree `T = (V, E)` stores: - A contiguous token slice `tau(u) = (t_i, t_{i+1}, ..., t_{i+k-1})` of length `|tau(u)| = k >= 1`. - A physical KV-cache block table mapping `pi(u)` in `N^k`. - A child lookup dictionary `delta(u): Sigma -> V` keyed strictly by the first token `t_i` of each outgoing child edge. - An atomic active sequence reference counter `rho(u) >= 0`. - A monotonic nanosecond access timestamp `alpha(u) > 0`. #### Theorem 1 (Deterministic O(L) Prefix Matching & Edge Splitting) For any incoming token sequence `Q = (q_1, ..., q_L)` of length `L`: 1. At any visited node `u`, looking up the candidate child edge `v = delta(u)[q_pos]` executes in `O(1)` expected time via hash table indexing on the leading token. 2. Comparing `Q[pos : pos + |tau(v)|]` against `tau(v)` performs at most `m = min(L - pos, |tau(v)|)` scalar integer comparisons, advancing `pos <- pos + m`. 3. If `0 < m < |tau(v)|`, node `v` is split at index `m` into an upper prefix node `v_upper` with `tau(v_upper) = tau(v)[0:m]` and lower suffix node `v_lower` with `tau(v_lower) = tau(v)[m:|tau(v)|]` in `O(|tau(v)|)` pointer slice operations without duplicating underlying KV tensor pages. 4. Summing across all traversed edges on the path from root to termination leaf yields total comparisons `sum(m) <= L`. Therefore, longest common prefix search and insertion run in strict `O(L)` time independent of total tree cardinality `|V|`. ### 2.2 Time-To-First-Token (TTFT) Reduction Formulation Given a sequence of length `L` where `M <= L` prefix tokens match cached nodes along path `P = (u_1, ..., u_m)`: - Uncached prefill compute latency scales as: `T_baseline(L) = t_init + c_prefill * L` - With Radix KV-Cache reuse of `M` tokens, prefill attention over the first `M` tokens is bypassed via zero-copy KV slot gather: `T_radix(L, M) = t_init + c_prefill * (L - M)` - The resulting TTFT Reduction Ratio is: `eta_TTFT = (T_baseline(L) - T_radix(L, M)) / T_baseline(L) = M / L` ### 2.3 Zero-Copy Reference-Counted LRU Eviction State Machine A node `u` in `V \ {root}` is eligible for eviction if and only if: `OutDegree(u) = |delta(u)| = 0 AND rho(u) = 0` When total allocated tokens `sum_{u in V} |tau(u)|` plus incoming suffix allocation `|Delta_Q|` exceeds capacity `C_max`: 1. All currently evictable leaves `L_0 = { u in V \ {root} : |delta(u)| = 0 AND rho(u) = 0 }` are organized into a binary min-heap keyed by `(alpha(u), id(u))`. 2. The minimum element `u_star` (oldest `last_access_ns`) is popped and unlinked from its parent `p = parent(u_star)`, reclaiming `|tau(u_star)|` token slots. 3. If removing `u_star` causes `|delta(p)| = 0` and `rho(p) = 0`, parent `p` immediately transitions to an evictable leaf and is pushed onto the min-heap. 4. This loop terminates once reclaimed tokens `>= overflow` or `L_0` is empty. --- ## 3.
