Mathematical Proof: Tiled Online Softmax Rescaling Standard scaled dot-product attention requires materializing an `N x N` intermediate matrix `S = (Q * K^T) / sqrt(d_k)`, incurring `O(N^2)` HBM read/write overhead. **GF-T3-226** partitions the key and value matrices into SRAM-resident tiles of size `B_c` (`16 tokens/block`) and maintains three running statistics per query row across tile iterations `j = 1 ... T`: 1. **Running Row Maximum (`m_j`)**: ```text m_j = max(m_{j-1}, max_{r in tile_j}(S_r)) ``` 2. **Exponential Rescaling Factor (`alpha_j`) & Partition Normalizer (`l_j`)**: ```text alpha_j = exp(m_{j-1} - m_j) l_j = l_{j-1} * alpha_j + sum_{r in tile_j} exp(S_r - m_j) ``` 3. **Unnormalized Output Accumulator (`O_tilde_j`) & Final Output (`O_T`)**: ```text O_tilde_j = O_tilde_{j-1} * alpha_j + exp(S_{tile_j} - m_j) * V_{tile_j} O_T = O_tilde_T / l_T ``` By induction, at termination `j = T`, `m_T = max_i(S_i)` and `l_T = sum_i exp(S_i - m_T)`, proving exact algebraic equivalence to naive scaled dot-product attention within IEEE-754 floating-point precision (`< 1e-7` absolute error) without materializing the `N x N` attention matrix in HBM. --- ## 3. Paged Virtual Memory Table & Eviction Mechanics - **Page Granularity**: `16` tokens per physical block (`B0` through `B15`). - **Logical-to-Physical Translation**: Sequences allocate physical blocks on demand. Non-contiguous physical blocks map to contiguous logical context windows, guaranteeing `0.0%` external fragmentation. - **Cumulative Attention Eviction**: Each block tracks running cumulative attention mass `A_b`.
