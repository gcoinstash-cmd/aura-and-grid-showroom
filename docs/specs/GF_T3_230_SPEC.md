Ring-AllReduce Mathematical Formulation ### 3.1 Communication Volume & Pass Complexity Given `N = 8` GPUs in a logical ring and a total gradient tensor payload of `M` bytes partitioned into `N` equal chunks of size `M / N`: - **Phase 1 (Scatter-Reduce)**: Executes `N - 1 = 7` synchronous ring passes. During step `k` (`0 <= k < N - 1`), GPU `i` transmits chunk `(i - k) mod N` to peer `(i + 1) mod N` while receiving and accumulating chunk `(i - k - 1) mod N` from peer `(i - 1) mod N`. - **Phase 2 (All-Gather)**: Executes `N - 1 = 7` synchronous ring passes. Each GPU forwards the fully reduced chunk around the ring without arithmetic overhead until all `N` GPUs hold the bit-identical reduced tensor. - **Total Transmitted Volume per GPU**: `V_ring = 2 * ((N - 1) / N) * M = 1.75 * M` ### 3.2 NVLink Fabric Latency Equation Total end-to-end AllReduce latency `T_allreduce` (in milliseconds) is governed by: `T_allreduce = 2 * (N - 1) * alpha_hop + (2 * (N - 1) * M) / (N * B_eff)` where: - `alpha_hop` = `0.0085 ms` per zero-copy DMA peer hop (`0.119 ms` base across 14 hops) - `B_eff` = `880 GB/s` nominal sustained NVLink bidirectional fabric bandwidth (`97.78%` efficiency of `900 GB/s` peak) - At `M = 64 MB` (`[4096, 4096]` FP32 chunk matrix), `T_allreduce = 0.14 ms`. ## 4.
