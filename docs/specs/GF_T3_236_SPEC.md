Mathematical Formulation (Block-Wise Online Softmax) Given query matrix `Q`, key matrix `K`, and value matrix `V` of dimensions `N x d`, standard attention materializes an intermediate `N x N` matrix `S = (Q * K^T) * scale` where `scale = 1 / sqrt(d)`. `GF-T3-236` partitions `Q` into row tiles `Q_i` of block size `B_r` and partitions `K, V` into column tiles `K_j, V_j` of block size `B_c` inside on-chip SRAM rings without materializing `N x N` matrices in HBM: 1. **Per-Tile Score Computation**: - `S_ij = (Q_i * K_j^T) / sqrt(d)` - When Causal Masking is active (`CAUSAL`), any coordinate `(row_r, col_c)` with `col_c > row_r` is masked to `-infinity`, and any tile block where `kv_start > q_end - 1` is bypassed completely prior to SRAM load. 2. **Online Running Maximum (`m_i`)**: - `m_i_new = max(m_i_prev, rowmax(S_ij))` 3. **Exponential Rescaling Factor (`alpha_i`)**: - `alpha_i = exp(m_i_prev - m_i_new)` - `P_tilde_ij = exp(S_ij - m_i_new)` 4. **Online Running Denominator (`l_i`) & Unnormalized Accumulator (`O_tilde_i`)**: - `l_i_new = alpha_i * l_i_prev + rowsum(P_tilde_ij)` - `O_tilde_i_new = diag(alpha_i) * O_tilde_i_prev + P_tilde_ij * V_j` 5. **Final Ring Normalization**: - `O_i = diag(1 / l_i_final) * O_tilde_i_final` --- ## 3.
