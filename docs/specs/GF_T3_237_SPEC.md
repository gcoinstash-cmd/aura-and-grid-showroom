Mathematical Formulation ### 3.1 Block-Wise Dynamic Scaling Factor Given a contiguous activation block `X = {x_0, x_1, ..., x_{N-1}}` of size `N`: 1. **Outlier Channel Isolation**: ```text mean_mag = (1 / N) * sum(|x_i|) std_mag = sqrt((1 / N) * sum((|x_i| - mean_mag)^2)) ``` Channels satisfying `|x_i| > mean_mag + k * std_mag` are routed to the sparse bypass index set `Omega`, leaving the filtered core tensor `X_core`. 2. **Filtered Absolute Maximum (`amax`) & Scale Factor**: ```text amax_filtered = max_{i not in Omega} |x_i| S_block = max(amax_filtered, 1e-8) / M_FP8 ``` where `M_FP8 = 448.0` for `E4M3` and `M_FP8 = 57344.0` for `E5M2`. 3. **8-Bit Floating-Point Grid Projection**: For each core element `x_i` in `X_core`, let `u_i = x_i / S_block`. With binary exponent `e = floor(log2(|u_i|))` and mantissa bit-width `m in {3, 2}`: ```text step_e = 2^(e - m) Q_FP8(u_i) = sign(u_i) * min(M_FP8, round(|u_i| / step_e) * step_e) ``` 4. **Signal-to-Quantization-Noise Ratio (SQNR)**: ```text SQNR_dB = 10 * log10( sum(x_i^2) / sum((x_i - x_hat_i)^2) ) ``` --- ## 4.
