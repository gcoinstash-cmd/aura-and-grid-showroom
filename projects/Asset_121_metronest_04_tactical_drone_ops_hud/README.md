# MetroNest-04 Delta: Tactical Drone Operations HUD

A high-performance mission control and autonomous verti-hub operations dashboard engineered for drone logistics dispatchers, fleet operators, and airspace controllers. Built with React 19, TypeScript, Tailwind CSS, Recharts, and Lucide Icons.

---

## 1. Product Truth & Disclosures Block

> **TRACK 1 PROTOTYPE DISCLOSURE**  
> This software artifact is a **Track 1 Prototype**: a zero-latency, high-fidelity frontend telemetry simulation powered by deterministic client-side reactive state loops (`useState`, `useEffect`, `useCallback`). 
> 
> - **Hardware Boundary**: This blueprint **does not** connect directly to physical drone autopilot flight controllers (e.g., PX4, ArduPilot, DJI Onboard SDK) or physical vertiport robotic bay actuators.
> - **Regulatory Boundary**: This software **does not** constitute FAA Part 135 air carrier certification, FAA Part 107 waiver compliance, or certified BVLOS (Beyond Visual Line of Sight) air traffic control authorization.
> - **Data Feed Boundary**: Airspace radar contacts, microburst hazard alerts, 5G mesh ping metrics, and battery swapping cycles are simulated using mathematical vector interpolation models and do not stream live FAA ADS-B or Mode-S transponder RF feeds without external API configuration.

## 2. Setup & Deployment Guide

Launch the mission control HUD locally in three zero-config commands:

```bash
# Step 1: Clone repository and install dependencies
npm install

# Step 2: Launch high-performance local Vite dev server
npm run dev

# Step 3: Build production-optimized static distribution bundle
npm run build
```

The application will be accessible at `http://localhost:3000`.
